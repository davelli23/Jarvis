# J.A.R.V.I.S. Dashboard

Futuristisches Dashboard (HUD-Stil) mit Wetter, Terminen, Systemstatus, Instagram-Kennzahlen und Sprachsteuerung („Jarvis, …“). Läuft im Browser und lässt sich als App aufs Handy installieren.

## Nutzung
- Am Bildschirm: Seite in Chrome/Edge öffnen, **F** = Vollbild, **Leertaste** = Mikrofon.
- Auf dem Handy: Seite öffnen, dann „Zum Startbildschirm hinzufügen“ bzw. „App installieren“.
- ⚙ SETUP: Stadt, Anrede, Kalender-Link (iCal), Instagram-Zugang. Wird nur lokal im Browser gespeichert.
- 🔔: Terminerinnerung 15 Minuten vorher.

## Sprachbefehle
Wetter · Termine heute/morgen · Uhrzeit · Datum · Internet · Instagram · Statusbericht · Aktualisieren · Vollbild

## Platzhalter
Ohne Kalender-Link bzw. Instagram-Token werden Demo-Daten gezeigt. Push bei geschlossener App braucht noch einen Server.
